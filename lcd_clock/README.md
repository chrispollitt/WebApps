# LCD Clock

Retro LCD clock PWA — clock, stopwatch, alarms, world clock.

Live: https://chrispollitt.github.io/WebApps/lcd_clock/

## Deploy

```bash
# From /home/chris/github/chrispollitt/WebApps/
cp -r lcd_clock <repo>/
git add lcd_clock
git commit -m "Add LCD Clock PWA"
git push
```

Then in GitHub repo → Settings → Pages → Source: `main` branch, `/` (root) or point to the folder.

## Install as PWA (Windows)

1. Open the GitHub Pages URL in Chrome or Edge
2. Click the install icon in the address bar (or ⋮ menu → "Install LCD Clock")
3. Done — it appears as a standalone app in your taskbar/Start menu
